# Portfolio curation

The main presentation now contains six collections and 23 screens. The full previous presentation remains available at `portfolio-archive.html`; no original artwork was removed.

## Selection rationale

1. **MechWarrior 5:** open with a recognisable, visually strong interface, then show the relationship between strategic navigation, mission planning, and maintenance. Four related screens demonstrate more range than an isolated hero image.
2. **Stardust Canvas:** bring the flowchart, sitemap, components, and typography together. These original artifacts provide concrete evidence of journey mapping and system thinking.
3. **Multiplayer UX explorations:** elevate the character, ability, lobby, mode-selection, and matchmaking studies that were previously buried under generic “Work Sample” labels. These are presented as explorations; no shipped status or specific client engagement is inferred from the branding visible in the artwork.
4. **Mobile UI & iteration:** show alternative visual directions, a screen family, a component board, and a separate interaction sequence. The style board proposes testing; the presentation does not claim testing took place or invent results.
5. **Fantasy card systems:** use the collection, deck builder, and detail view to explain information hierarchy and how related interfaces support decision-making.
6. **Motion & AI-assisted concepts:** retain the personal motion work as a distinct collection after the studio interfaces and UX artifacts.

## Presentation decisions

- Retain the full-viewport slideshow and the main site's cream, sage, green, and DM Sans styling.
- Provide project-level navigation and a separate screen sequence within each project.
- Pair each artifact with a short description of visible design decisions rather than generic promotional copy.
- Add an original-size image viewer so dense journey maps and wireframes can be read.
- Support direct links using `portfolio.html#project-id/screen-number`.
- Keep additional work available through the project browser's archive link.

## Evidence and remaining gaps

The initial curation used original artifacts. The UX extension adds six retrospective walkthroughs and three interactive concept studies with generated environments supporting live HTML interfaces. Original work, reconstructed explanations, and proposed states are explicitly distinguished. See UX_STUDIES.md for provenance and prompts.

The new explanatory text is an editorial reading of the visible interfaces, not a reconstruction of research history. A fuller case study would benefit from Remi's confirmation of exact responsibilities, constraints, collaborators, why alternatives were chosen, and any documented outcomes. Those facts should be added from source material rather than inferred from screenshots. Existing studio attributions were retained only for the clearly named collections.
