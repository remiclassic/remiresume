# Sports UI & UX — FACE/OFF and TOUCHLINE

Independent 2026 portfolio concept for discussing AI-assisted sports UI. Not commissioned or endorsed by EA. All clubs, athletes, ratings, and game rules are fictional/illustrative. Four raster UI art screens were created with the built-in image-generation tool. HTML UX walkthroughs explain decisions, controller focus, cancellation, validation, and proposed research; no measured outcomes are claimed.

## Public reference direction

- [EA NHL 26 HUT presentation](https://www.ea.com/games/nhl/nhl-26/news/nhl-26-hut-deep-dive)
- [EA FC 26 FUT presentation](https://www.ea.com/fr/games/ea-sports-fc/fc-26/news/pitch-notes-fc26-fut-deep-dive)

These informed the broad club-hub and team-management direction; the generated interfaces are original concept proposals, not screenshots of EA products.

## Production scope

The images are UI art, not playable game interfaces. The surrounding portfolio navigation and UX walkthroughs are interactive. Implementation would require native text and controls, reusable component definitions, directional focus rules, localization layouts, contrast verification, and validated save/error states. Generated brand/portrait details vary between mockups and would need a consistency pass before production.
